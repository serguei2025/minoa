# Minoa

Application personnelle (web app installable / PWA) : tâches, agenda, budget, repas, projets, portfolio, voiture et carnet d'alternance.

- Ouvre l'adresse GitHub Pages dans Safari sur iPhone, puis **Partager › Sur l'écran d'accueil**.
- Les données saisies restent uniquement sur l'appareil (stockage local du navigateur) : ce dépôt ne contient aucune donnée personnelle.
- Sauvegarde / restauration : **Plus › Réglages › Exporter mes données / Importer une sauvegarde**.
